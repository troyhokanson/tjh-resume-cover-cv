# Repository Instructions for AI Agents

These instructions apply to every AI agent, coding assistant, resume builder, workflow, and document-generation process operating in this repository or using it as a template source.

## Mandatory Read Order

Before drafting or changing any resume, CV, cover letter, recruiter packet, professional bio, portfolio entry, or application package, read:

1. `SOURCE_OF_TRUTH_ROUTING.md`
2. `CAREER_CONSTANTS.md`
3. `TEACHING_FACULTY_CONSTANTS.md` when teaching, training, education, academic, customer-success, implementation, or facilitation experience may be relevant
4. `CASE_BANK.md` when investigative examples or outcomes may be relevant
5. `VOICE_STANDARD.md`
6. `PROFILES.md` and `PROFILE_SELECTOR.md`
7. The applicable design standards

## Hardline Writeback Rule

Whenever Troy confirms, corrects, clarifies, or improves a reusable fact or description, update the correct authoritative GitHub source during the same working session and on the same branch or pull request as the application work.

A tailored application file is not an authoritative source.

Do not finalize an application when a new reusable fact exists only in:

- chat history;
- an application-specific Markdown file;
- a generated DOCX or PDF;
- a pull-request description; or
- a correction or override sidecar.

Route the information according to `SOURCE_OF_TRUTH_ROUTING.md`, update the authoritative source, update the tailored document, and verify that both agree.

## Conflict Rule

If two sources disagree, stop and resolve the authoritative record before finalizing the document. The narrower source controls its subject. `TEACHING_FACULTY_CONSTANTS.md` controls teaching and faculty information.

## No Silent Invention

Do not infer dates, awards, metrics, credentials, durations, course requirements, case outcomes, or role scope. Use verified repository facts or clearly mark the information as requiring confirmation.

## Completion Requirement

At handoff, state which authoritative source was updated and identify the branch or pull request containing the change.

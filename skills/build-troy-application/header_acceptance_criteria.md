# Troy Application Header Acceptance Criteria

These criteria apply whenever the branded navy-and-gold header is selected for a Troy Hokanson resume, cover letter, CV, recruiter packet, or related application document.

## Full-Bleed Requirement

The navy header field must be a single uninterrupted rectangle across the full physical page width.

Required:

- Navy touches the top physical page edge.
- Navy touches the left physical page edge.
- Navy touches the right physical page edge.
- No white strip, sliver, margin, seam, or unfilled corner may appear at the top, left, or right.
- The full header height remains navy from its top boundary through its bottom boundary.
- The white document body begins only below the completed navy header field.
- There is no white band inside the header above, below, or between the name, gold rule, and contact row.

This does not mean the entire page is navy. Only the designated page-one header block is navy; the body below it remains white.

## Header Content

Use only:

1. `Troy Hokanson`
2. Centered gold rule directly below the name
3. One centered contact row in this exact order:
   - phone
   - email
   - LinkedIn
   - `TroyHokanson.com`

Do not include:

- middle initial
- city or state
- street address
- ZIP code
- subtitle
- role title
- tagline
- relocation note
- `Remote`
- icons unless explicitly approved for a specific non-ATS presentation document

## Hyperlinks

Where supported:

- phone uses a `tel:` hyperlink
- email uses a `mailto:` hyperlink
- LinkedIn uses the approved profile URL
- portfolio uses `https://TroyHokanson.com`

Visible text must stay clean and concise. Do not display tracking parameters or long raw URLs.

## Visual Standard

- Name: white, bold Garamond-family type, centered
- Gold rule: thin, restrained, centered, directly beneath the name
- Contact row: centered and visually balanced beneath the rule
- The entire name-rule-contact composition must be centered against the physical page, not merely the body margins
- No footer by default
- Page 2+ uses the approved thin navy continuation header with `Troy Hokanson` only

## Validation

Every branded resume and cover letter must be validated independently.

A pass requires:

- top edge fully navy
- left edge fully navy
- right edge fully navy
- no internal white gap within the header field
- name centered
- gold rule centered
- contact row centered
- no prohibited header content
- all hyperlinks functional where supported
- required spacing between the completed header and first body heading

Rendered output controls. Word, DOCX, or PDF alignment settings alone do not establish a pass.

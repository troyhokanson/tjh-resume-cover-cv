# Troy Hokanson Application Header Identity Standard

This file is a hard contract for every Troy Hokanson resume, cover letter, CV, recruiter packet, and branded application document produced by `build-troy-application`.

## Page-One Identity

Use exactly:

```text
Troy Hokanson
```

Do not use:

- Troy J. Hokanson
- Troy Jared Hokanson
- initials or alternate name forms

## Gold Rule

Place one thin gold rule directly beneath `Troy Hokanson`.

Required presentation:

- color: approved repository gold
- centered on the physical page
- approximately 55 percent of page width
- approximately 0.90 point thickness
- visually close enough to read as an underline for the name, while preserving clean separation
- no second decorative line

## Contact Row

Display exactly four contact items, in this order:

1. Phone
2. Email
3. LinkedIn
4. TroyHokanson.com

Current approved visible form:

```text
612-352-8647 | TroyHokanson@iCloud.com | linkedin.com/in/troyhokanson | TroyHokanson.com
```

The active repository contact constants control if a verified contact value changes.

## Hyperlinks

Where supported by the output format:

- phone uses a `tel:` hyperlink
- email uses a `mailto:` hyperlink
- LinkedIn links to the approved LinkedIn profile
- TroyHokanson.com links to `https://TroyHokanson.com`

Hyperlink display text must remain clean. Do not expose tracking parameters or unnecessarily long URLs.

## Prohibited Header Content

Do not include:

- Lakeville, MN
- city, state, ZIP code, or street address
- relocation language
- remote-work language
- a role title
- a professional tagline
- an objective statement
- labels such as `LinkedIn`, `Portfolio`, or `Investigative Portfolio`
- more than one email address
- obsolete ProtonMail or pm.me addresses
- icons unless Troy explicitly approves them for a particular document

## Page-Two and Later Header

Use a slim navy continuation bar containing only:

```text
Troy Hokanson
```

Do not repeat contact information on continuation pages.

## Alignment and Spacing

- Center the complete name-rule-contact composition against the physical page.
- Maintain the approved full-bleed navy background when the branded header is selected.
- Maintain at least 18 points of visible white space between the bottom of the page-one header and the first body heading or salutation.
- Do not compress the header or body transition to recover page space.

## Validation

Every final packet must verify:

- exact name text is `Troy Hokanson`
- no middle initial appears in the header
- no location appears in the header
- exactly four contact items appear in the required order
- all four items are hyperlinked when the format supports hyperlinks
- the gold rule is present, centered, and directly below the name
- no subtitle or tagline is present
- continuation headers contain only `Troy Hokanson`
- the rendered page passes physical centering and header-to-body spacing checks

A packet fails visual QA if any of these requirements are not met.
